# 🏋️ Fitness Center Management System

A web-based **Fitness Center Management System** developed as an academic project to simplify and manage the daily operations of a fitness center.

The system provides separate functionalities for administrators, members, and trainers, including member management, trainer management, membership plans, fitness classes, attendance tracking, and reviews.

## ✨ Features

### 👨‍💼 Admin
- Admin login
- Manage members
- Add, update, and delete trainers
- Manage fitness classes
- Manage membership plans
- View attendance records
- View member reviews

### 👤 Member
- Member login and logout
- View member profile
- View available membership plans
- View fitness classes
- View trainers
- Check in and check out
- Submit and edit reviews

### 🏋️ Trainer
- Trainer login and logout
- View trainer profile
- Access trainer dashboard
- Manage relevant fitness center activities

## 🛠️ Technologies Used

- Java
- Jakarta Servlets
- JSP (JavaServer Pages)
- HTML
- CSS
- Maven
- Apache Tomcat
- Object-Oriented Programming (OOP)
